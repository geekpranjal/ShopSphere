# ShopSphere — Frontend

This is the React frontend for **ShopSphere**, a full-stack MERN e-commerce platform.

> For full setup instructions, see the [root README](../README.md).

## Quick Start

```bash
# From the project root:
npm run dev
```

The frontend runs on [http://localhost:3000](http://localhost:3000) and proxies API calls to `http://localhost:5000`.

## Tech

- React 18 (Create React App)
- Redux Toolkit (cart state)
- React Router v6 (routing)
- Context API (JWT auth session)
